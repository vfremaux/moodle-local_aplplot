This plugin centralizes a set of Plotting third party plugins for improving graph and data
presentation in APl plugins serie. This library is inclined to evolve by:

- Integrating new frameworks when discovered and checked that they might have some recurrent utiity.
- Extending existing support of already integrated frameworks to extend use cases and presets availability

Integrated frameworks:

- General JQuery JQWidgets bank
- MIT JQPlot framework
- Jquery sparklines
- Timeline
- Googlemaps
- CharJSplus as an enhancement of core chartjs inegration

Most frameworks are partially integrated from our practical needs in our plugins. We have designed
front "facades" to have a moodle codingstyle compatible API to use them. Do not expect finding
complete and exhaustive APIs, as this is NOT the purpose of this plugin.
